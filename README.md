# YouTube Chatbot 🎥💬

A YouTube chatbot that extracts the transcript of a YouTube video and uses LangChain and OpenAI to answer questions based on the video content.

## Features

- Extracts YouTube video transcripts
- Processes transcript into text chunks
- Creates embeddings using Hugging Face
- Uses FAISS for vector storage and similarity search
- Uses LangChain for document processing and retrieval
- Uses OpenAI to generate answers
- Allows users to ask questions about a YouTube video

## Technologies Used

- Python
- Jupyter Notebook
- YouTube Transcript API
- LangChain
- LangChain Community
- LangChain OpenAI
- OpenAI API
- Hugging Face
- FAISS
- Python-dotenv
